# DSP Studio

《数字信号处理B》课程项目，v0.1.0。**本机实时连续采集、处理和播放**，不是以文件批处理代替实时功能。

## 启动

首次从 GitHub 克隆或下载后，需要 Windows 和 Python 3.11。在项目目录运行以下命令安装依赖并下载声纹模型：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
.\launch.cmd
```

本机已有项目内 `.venv` 时，可直接双击 **launch.cmd** 打开桌面界面；不会自动打开麦克风。源码仓库不包含本地环境、模型权重、真实录音、组员声纹档案或个人设置，模型由安装脚本从上游下载。

最新界面与验证：[深色工作台](validation/long-session/dark-1440x900-scale-1.png)、[历史会话试听（合成验证数据）](validation/long-session/light-history-controlled-scale-1.png)、[长时波形与会话说明](docs/09_长时波形与会话录音.md)、[验证汇总](validation/long-session/summary.json)。

界面采用紧凑工作台：顶部连接设备并启动/停止；左侧“音效”“声学回声”“组员”“设置”页签设置参数，右侧切换波形与频谱并查看当前说话人。底部控制监听，“运行详情”查看延迟、欠载和超时。支持深浅外观；Ctrl+Enter 启动/停止，Ctrl+S 导出最近音频。未采集音频时导出不可用。

启动实时处理时默认自动保存完整会话。默认目录为 `data/recordings/`，四路FLOAT WAV约0.92 GB/小时，每10分钟分段，停止后自动收尾。可在“设置”中关闭下次会话的自动录音或选择目录；程序不会自动删除旧录音。“导出最近30秒”仍是独立操作。

波形默认显示10秒，时间从本次采集开始计算。“设置”中可选2、5、10、30、60、300、600秒，波形和频谱默认锁定纵轴，仅允许横向拖动和缩放。拖动后取消“跟随实时”，录音继续；“显示整段”查看本次全部已保存波形，“复位视图”恢复标准坐标和跟随。若关闭自动录音，只能回看仍在30秒内存缓存中的音频。

停止采集后，点顶部“会话”打开历史会话。历史模式支持波形回看、播放/暂停、进度跳转、原始与处理后音轨切换，底部音量控制试听；频谱跟随播放位置。历史试听与实时采集互斥，点“返回实时”重新采集。历史模式不对旧录音重新识别说话人或重新应用音效。

当前界面以 DSP Studio 为唯一正式名称，参照 EtherScope 2.3.0 预览版采用紧凑工具条、深灰/浅灰两套底色、黄色启动按钮、13px正文、等宽数字与细线分区。窄窗口将设备与动作分行，长设备名在中间省略并保留接口类型，下拉与提示提供全文；运行中的停止按钮为红色轮廓。右上角太阳/月亮按钮切换外观，问号打开说明。标题栏支持拖动、双击最大化、还原、最小化和关闭。延续直角组件与精简文案，识别区不显示窗口时长和更新频率的常驻小字。原始曲线为灰色虚线，处理后为金色实线，悬停可查看实际采样点读数；每轮新采集清空旧曲线和旧读数。

新机器需要Python 3.11，在此目录运行 `setup.ps1` 安装依赖和下载约28 MB的CAM++声纹模型。首次安装需要网络；模型准备好后推理不使用外部服务。当前开发环境的完整版本见 `requirements-lock.txt`。

## 建议演示顺序

1. 选择麦克风和耳机，输入、输出的方括号接口类型保持一致，例如都选择WASAPI；点击“启动实时处理”。
2. 保持安静，点击“学习环境噪声  1秒”，再连续讲话；打开“监听输出”试听，切换“频谱降噪”比较。
3. 打开“产生回声”，调整延时和比例；再打开“消除刚产生的回声”。此模式验证已知路径逆滤波。
4. 真实AEC实验：关闭监听，输出选择扬声器，加载一段实际采集的语音作为远端参考；启用循环播放、声学回声消除和更新回声模型。保持安静数秒学习路径，然后关闭“更新回声模型”，再讲话。用导出的AEC残差与麦克风录音比较。首版尚无自动双讲检测。
5. 组员注册：关闭参考播放、由一人连续说话。输入姓名，点击“采集6秒并注册”，每人建议用不同句子注册3次。开启连续识别，使用新句子测试，另请非组员测试未知人拒识。
6. 点击“停止处理”完成整段会话保存，之后从“会话”回看并试听。也可点击“导出最近30秒”另存最近窗口。关闭窗口会停止设备并收尾录音。

监听默认关闭，建议使用耳机进行数字回声实验，避免近距离扬声器监听形成啸叫。扬声器的参考播放与耳机监听是两个不同实验场景。

## 已接入模块

| 要求 | 实现 |
|---|---|
| 真实环境输入 | PortAudio全双工麦克风输入，16 kHz / 单声道 |
| 实时语音增强 | 512点FFT，sqrt-Hann窗，50%重叠，噪声谱学习与维纳型增益 |
| 回声产生 | 可调20–600 ms延时、0–0.85回声比例的FIR |
| 数字回声消除 | 已知延时/比例的因果逆滤波 |
| 声学回声消除 | 2048抽头参考式NLMS，支持学习/冻结和重置 |
| 组内说话人识别 | CAM++预训练模型、本地注册、3秒窗口后台识别、未知人拒识 |
| 人机界面/输出 | Qt桌面界面、波形/频谱、参考播放、实时耳返、WAV导出 |

音频引擎运行在独立进程，Qt绘图和声纹推理在界面进程中运行，通过共享内存读取最近波形。算法固定延迟为256样本，即16 ms；总延迟还包括音频设备缓冲。界面总延迟显示为设备报告值加算法延迟，**尚不是声学回环测得的端到端延迟**。语音识别窗口3秒是声纹判断所需的观察时间，不会把声音输出延迟3秒。

## 限制

- 这是课程首版。普通房间中AEC效果、双讲、持续稳定性以及真实组员识别准确率需单独验收。
- 频谱降噪主要针对已学习的平稳背景噪声，不承诺去除所有键盘声、风声或其他说话人。
- 真实AEC必须有实际播放参考；仅打开开关而没有参考声音不能消除任意房间混响。
- 首版AEC需要远端单讲学习和手动冻结，不能宣称达到WebRTC等成熟引擎的双讲性能。
- 声纹前处理是能量门限，不是神经语音活动检测；注册至少需要1.5秒有效声音，识别至少1秒，总录音均至少2秒。高噪声和多人同时讲话会影响结果。相似度不是概率，不用于安全身份认证。
- 声纹默认阈值未按组员校准。公开音频测试通过不能代替组员测试。
- 固定16 kHz输入/输出；若设备拒绝，请选择同接口的其他设备条目。首版不自动重采样设备时钟、不支持虚拟麦克风。
- 本轮没有生成课程最终报告或冒充已完成组员实测。

验证命令：`.venv\Scripts\python.exe -m pytest -q` 和 `.venv\Scripts\python.exe tools/validate.py`。硬件短测使用 `--hardware`，只运行3秒、输出静音、不保存或回放采集内容。

界面并发短测：`.venv\Scripts\python.exe tools/validate_gui.py`，持续约25秒，使用真实麦克风但输出静音，仅记录统计，不保存采集内容。

完整会话联测：`.venv\Scripts\python.exe tools/validate_full_session.py`，至少2分钟，麦克风录音写入临时目录；验证完整保存、四路尾部样本一致、浏览不中断录音、历史输出设备与跳转，声音输出保持静音，结束后删除临时录音，只保留统计JSON。

项目目录以外的教材、课件和习题答案未修改。
