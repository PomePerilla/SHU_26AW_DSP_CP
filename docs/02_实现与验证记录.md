# v0.1.0 实现与验证记录

日期：2026-10-28。范围为课程项目首版，不是完整课程验收或商业音频产品认证。

## 实现结果

程序名称：**DSP Studio**。入口 `app.py`，本机双击 `launch.cmd` 启动。

音频链：真实麦克风 → 参考式NLMS声学回声消除 → 512点FFT/WOLA频谱增强 → 数字回声产生/已知路径逆滤波 → 可控监听输出。

实际送往播放设备的限幅后信号，延后一块后作为AEC参考历史。音频处理固定16 kHz、每块256样本，WOLA固定引入256样本延迟。设备缓冲、声学传播和系统调度需要另外计入总延迟。

音频引擎位于独立子进程，GUI绘图与声纹模型不与音频回调共用Python解释器。最近30秒的四路数据通过共享内存单写入者环形缓冲提供给界面；控制指令和统计通过管道由非回调线程处理。声纹识别使用3秒观察窗口和后台单任务队列，不阻塞声音输出。

## 已执行验证

### 数字信号与状态连续性

`python -m pytest -q` 的最终结果记录为 **8项通过**，覆盖：

- WOLA旁路还原及精确一块延迟。
- 已知数字回声的分块逆滤波。
- NLMS学习线性回声路径、冻结后保留独立近端信号。
- 已知合成有噪信号上的频谱增强。
- 环形缓存回绕与四路样本对齐。
- AEC使用实际限幅后播放信号作为参考。
- 全模块开启时的静音数值稳定性。
- 连续麦克风输入经处理和监听增益后路由到输出缓冲。

### 实时预算与合成回声

原始结果：`validation/results.json`。

- 全部DSP模块开启的1200块合成回调循环，等效19.2秒音频：平均约0.807 ms/块，P95约1.032 ms，最大约1.795 ms；16 ms预算下0块超时。
- 指定线性回声路径、近端静音的合成实验，末2秒ERLE约61.2 dB。
- 数字回声逆滤波最大绝对误差约 `5.96e-8`。

这些是合成输入结果，不代表房间回声衰减、实际录音音质或端到端低延迟。

### 公开声纹录音冒烟

使用sherpa-onnx官方发布附件，临时档案目录与正式组员档案隔离；注册与测试文件不同。

| 用例 | 相似度 | 结果 |
|---|---:|---|
| 已注册公开样本A的另一段录音 | 0.710 | 识别为A |
| 已注册公开样本B的另一段录音 | 0.820 | 识别为B |
| 未注册的第三位公开说话人 | 最高0.392 | 拒识为未知 |

默认相似度阈值0.55、前两名差值0.05。此处只有3个测试用例，不能据此报告组内识别准确率。最终运行中5.57秒语音的一次嵌入提取耗时约0.048秒，属于本机单次观察，不是模型通用延迟指标。

### 本机音频硬件与界面并发

- 初始3秒双工短测：Intel麦克风阵列输入、Realtek扬声器输出，MME接口；输出静音，不保存采集内容；欠载/超时/削波为0。
- 最终生产结构的25秒联测：Qt持续绘制波形与频谱、后台提交13次公开录音声纹推理任务、真实麦克风连续输入、全部DSP模块开启；音频引擎为独立进程。
- 联测结果：欠载0、处理超时0、削波块0，观察到的处理耗时峰值约1.116 ms。详细数据见 `validation/gui-live.json`。
- 设备报告I/O延迟为16 ms输入、96 ms输出，加16 ms算法延迟，界面估算128 ms。**未进行声学回环测量**。
- 通过computer-use检查窗口、波形/频谱显示、噪声学习反馈和设备运行状态。小屏幕使用滚动区域展示完整功能，启动时默认最大化。

短测使用静音输出，不能据此宣称扬声器/耳机听感或真实AEC已经验收。
