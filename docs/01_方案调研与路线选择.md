# 数字音效处理系统：方案调研与路线选择

调研日期：2026-10-28。研究方式：上游代码、官方产品文档和模型资料的桌面调查；没有购买商业软件，也没有进行跨产品音质实测。下文对优劣的评价是面向本课程的工程判断，不是产品性能排名。

## 1. 当前有效要求

以用户本次给出的要求为准，覆盖旧课件的不同项目描述：

1. 语音输入来自真实环境的麦克风采集。
2. 实现语音增强、回声产生和消除、项目组内说话人识别。
3. 使用人机交互界面，支持扬声器或耳机输出。
4. 用户进一步确认：**必须实时连续处理**，录音后批处理不能作为主要交付。

课程联系：第1章的采样、数字信号与系统；第2章的DFT/FFT、卷积、频谱分析；第3章的FIR/IIR结构、频率响应和滤波器设计。自适应滤波和声纹模型属于为项目补充的内容，报告中应说明来源。

## 2. 必须区分的概念

- **语音增强**：降低背景噪声，不等于识别文字。
- **说话人识别**：把一段声音与已注册组员的声纹进行比较，不等于语音转文字、多人分离或活体认证。
- **数字回声效果**：人为产生 `y[n] = x[n] + g·x[n-D]`，参数已知时可以做逆滤波。
- **声学回声消除 AEC**：已知实际扬声器播放参考 `r[n]`，从麦克风 `d[n] = v[n] + h[n]*r[n]` 中估计并去掉播放回声。
- **去混响**：改善房间反射造成的拖尾；没有播放参考的单通道去混响不能直接冒充参考式AEC。

## 5. 四套可实施方案草稿

### A. 全经典DSP教学版

- Python + Qt + PortAudio。
- 语音增强：STFT/维纳型频谱增益；数字回声：延时FIR与逆滤波；物理AEC：NLMS。
- 声纹：MFCC统计特征 + GMM/SVM，自己采集并训练。
- 优点：最容易解释与展示课程推导。
- 风险：少样本声纹泛化不确定，必须严格分离注册句子和测试句子。
- 适合：评价重点偏推导、允许声纹效果一般的课程。

### B. 经典DSP + 预训练声纹桌面版（选定）

- Python 3.11 + PySide6 Essentials + sounddevice/PortAudio + NumPy/SciPy/Numba。
- 主音频链为16 kHz、单声道、256样本/块；频谱处理使用512点FFT。
- 保留A的可解释降噪、回声产生/逆滤波和参考式NLMS AEC。
- 声纹改用CAM++ ONNX，通过sherpa-onnx在CPU后台推理，3秒窗口、约2秒一次更新。
- 适合：本课程的算法展示、实时交互和小组成员识别兼顾。
- 风险：NLMS首版对双讲需要手动冻结；非平稳噪声、长混响、扬声器非线性条件下不能承诺商用效果。

### C. 原生实时通信增强版

- C++/Qt + WebRTC APM/AEC3 + RNNoise或DeepFilterNet + ONNX声纹。
- 优点：采用成熟实时语音模块，长期可形成更完整的音频产品。
- 风险：Windows构建、原生依赖与线程时序集成较重，课程报告中自主DSP实现占比更少。
- 适合：有充足工期与C++音频经验、对复杂声学环境要求更高的团队。

### D. MATLAB App Designer版

- App Designer + Audio Toolbox + DSP System Toolbox + 声纹预训练模型/自建分类器。
- 优点：课程衔接好，滤波器分析与仿真方便。
- 风险：授权和成员机器环境；真实硬件全双工性能仍须测量，不能用离线脚本运行成功替代。
- 适合：所有组员已有工具箱授权、教师希望MATLAB交付的情况。

## 7. 首版实现边界与验收

1. **实时链路**：独立音频进程通过同一双工流采集和播放，初始化时完成Numba编译。Qt绘图和声纹后台任务处于另一个进程；波形用单写入者的共享内存环形缓冲传递，音频回调不进行进程管道读写。记录每块处理时长、超时、设备欠载及削波。
2. **增强**：显式采集1秒环境噪声，sqrt-Hann WOLA和维纳型增益；不在噪声条件未知时伪造SNR提升。
3. **数字回声**：可调延时和比例；已知参数逆滤波仅抵消本系统生成的回声，不等于盲去混响。
4. **物理AEC**：2048抽头NLMS，覆盖相对于参考对齐起点的128 ms路径。使用上一块实际播放信号作为参考；硬件时延与残响超出覆盖范围会影响效果。先远端单讲学习，再冻结并进行近端讲话；自动双讲检测尚未实现。
5. **声纹**：本地注册、累计多个样本的归一化嵌入、余弦打分及未知人拒识；默认阈值0.55、前二名差值0.05只是起点，需要组员留出录音校准。
6. **数据**：持续处理只保留最近30秒内存；只有主动导出才写入麦克风/处理后/播放参考/AEC残差WAV。注册只保存声纹向量，不自动保存原始注册语音。
7. **验证分层**：数字合成信号验证算法；公开上游录音做声纹接口冒烟；本机静音输出短测验证音频设备运行；真实组员、不同噪声和房间回声另外验收，不能互相替代。

## 8. 后续必要工作

- 每名组员用不同句子注册至少3次，另录未参与注册的测试句子；增加至少一位非组员作为拒识测试。
- 同设备、跨天、跨设备分别统计识别准确率、未知人误接收和已知人误拒绝。
- 扬声器/麦克风实测远端单讲、近端单讲、双讲、路径变化和不同音量；ERLE只在能分离远端回声、近端静音的条件下报告。
- 若手动冻结不能满足验收，优先引入SpeexDSP/WebRTC AEC3，而不是无限叠加NLMS参数。
- 至少进行一次持续10分钟的实际实时运行与听感检查；本轮短测结果不能替代它。
