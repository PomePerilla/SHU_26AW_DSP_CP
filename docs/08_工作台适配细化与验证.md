# 工作台适配细化与验证

日期：2026-10-29。入口：`launch.cmd`。主题：`ui/generated-etherscope-v2/`。

## 修改

- 工具条小于1120逻辑像素时分为设备、动作两行，增加设备名称可读宽度；宽窗口保持一行。1120来自当前界面契约，通过同一控件布局移动实现，不重建采集服务、设备选择和草稿。
- 设备名称中间省略，保留首尾及MME/WASAPI等接口类型。完整名称和设备ID仍在原模型中，提示和下拉保留原文，下拉按内容扩宽并考虑屏幕边界。
- 数值字段统一宽度、右对齐；分组标题改为轻分隔线，学习噪声、选择参考、重置、声纹注册统一线性图标及左对齐。
- 黄色启动与红色轮廓停止区分状态，图标与已有动作启用条件对应。输入设备异常但仍有待关闭的流时继续显示停止。
- 参考文件名、识别结果较长时省略显示并保留全文提示。图表等待提示相对实际绘图区居中，随工具条重排和页签切换重新定位。
- 新采集启动成功后清除上一轮曲线及悬停/可访问读数，恢复等待态。换肤、窗口重排仍保留当前曲线与音频任务；尚无帧耗时统计时显示“—”，避免显示虚构的0。
