# DSP Studio 名称与直角界面调整

日期：2026-10-29。入口：`launch.cmd`，已打开的旧窗口需重新启动才会载入新样式。

## 修改

- 窗口标题、应用名称、顶部唯一标识、当前配置与说明文档统一使用 **DSP Studio**。
- Qt按钮、输入框、复选框等改为直角；页签使用下划线选中态，输入框使用底线，次要按钮去除常驻外框，内容区域通过留白和细分隔线组织。
- 状态文字去除胶囊底色，组员识别结果去除四周卡片框，保留顶部细线。
- 删除识别区常驻的窗口时长、更新频率说明，空白说明行折叠；注册指导、识别读数和异常提示仍按需显示。
- 算法采样窗口和识别周期保持原值，修改仅作用于名称和界面呈现。

当前主题为 `ui/generated-flat-v1/`。管线基础schema要求半径为正值，基础token采用1px；Qt适配由 `presentation.qt_corner_radius=0` 覆盖为直角。没有修改用户的技能包。此前生成物、截图和检查JSON保留作历史证据。
