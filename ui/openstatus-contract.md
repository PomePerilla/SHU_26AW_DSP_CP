# OpenStatus-inspired 前端契约

历史设计记录。2026-10-29后续已按用户新要求转为 EtherScope 风格，当前规范见 `etherscope-contract.md`；以下记录对应早期版本。

本轮增量调整桌面前端。沿用 Qt Widgets、pyqtgraph、已有页签和独立音频进程，不增加依赖、导航业务或演示指标。

## 审查结果

1. 主按钮、活动页签、当前说话人和处理曲线共用青绿色，操作、状态与数据的职责不清晰。
2. 组员表格的次数、相似度未右对齐；实时读数尚未采用稳定的数字字形。
3. 控件、来源行与图表分隔方式不一致，部分输入边框和按钮悬浮反馈偏重。
4. 空闲图表只有坐标轴，缺少靠近图表的下一步提示。
5. “运行详情”把字段与读数放在同一段文本中，数字难以快速纵向比较。

正式名称统一为 DSP Studio。保留两栏操作与观察结构、参数值、深浅切换、键盘操作、真实音频与声纹状态。没有采用 OpenStatus 品牌或其监控业务。

## 设计规则

- 个性：精确、克制，优先当前数据与操作。
- 中性工作区 → 控制面 → 图表/结果 → 临时对话框；以单像素边界区分，不增加卡片嵌套。
- 默认深色，浅色同步维护。主操作用中性反差；绿色、琥珀、红色分别用于正常、准备与错误，均保留文字。蓝色只用于处理曲线和信息提示。
- 中文正文使用现有 Microsoft YaHei UI 14px，英文标识和数值使用 Segoe UI；数值字体启用 OpenType `tnum` 等宽数字，数值列右对齐，不下载新字体。标题20px、识别结果18px、辅助说明12px。
- 4/8/12/16/20/24间距，36像素控件与表格行，Qt组件采用直角。顶部仅保留 DSP Studio 标识。
- 中性底色略带冷灰，主操作保持克制的明暗反差；页签采用下划线选中态。次操作与辅助操作去除常驻外框，悬浮显示底色、键盘焦点显示轮廓。线性图标统一16px，纯图标按钮具备名称与提示。
- Qt组件使用0px圆角。输入框采用底线，图表和操作区去除卡片外框，结果区仅保留顶部细分隔线。生成器要求基础radius为正值，基础token取1；Qt适配使用 `presentation.qt_corner_radius=0` 明确覆盖。
- 识别区删除窗口时长和更新频率的常驻说明，空说明行隐藏；注册、识别结果和错误信息按需显示。
- 图表只保留稀疏主刻度：波形0.5秒/0.5幅度，频谱2kHz/20dB。坐标范围、读数和数据来源不变。
- 原始曲线为灰色虚线、处理后为蓝色实线，配有图例、单位与时间范围。无采集数据时显示明确等待提示；设备尚未连接时详情值显示“未连接”或“—”。
- hover、focus、selected、disabled在两套主题中统一。切换主题不重启音频，不新增装饰动画。
- 适配900×580、1024×768、1440×900桌面逻辑尺寸；移动端不在当前Qt应用支持范围。
